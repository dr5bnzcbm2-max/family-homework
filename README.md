# 숙제·일정 가족 웹앱

초2 딸의 오늘 숙제·준비물 체크, 요일별 주간 일정, 칭찬 스티커판을 한 화면에서 보는 가족용 웹앱입니다.

## 쓰는 방법

- https://dr5bnzcbm2-max.github.io/family-homework/ 를 iPhone Safari로 엽니다.
- 공유(⬆️) → **홈 화면에 추가** 를 누르면 앱처럼 전체 화면으로 열립니다.
- 입력한 내용은 그 기기 브라우저에만 저장됩니다(localStorage). 공유 탭에서 백업·복원할 수 있어요.
