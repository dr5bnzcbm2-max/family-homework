# 숙제·일정 가족 웹앱

초2 딸의 오늘 숙제·준비물 체크, 요일별 주간 일정, 칭찬 스티커판, 가족 한마디(코멘트)를 한 화면에서 보는 가족용 웹앱입니다.

## 쓰는 방법

- https://dr5bnzcbm2-max.github.io/family-homework/ 를 iPhone Safari로 엽니다.
- 공유(⬆️) → **홈 화면에 추가** 를 누르면 앱처럼 전체 화면으로 열립니다.
- 같은 **가족 방 코드**(기본 `torchi-family`)를 쓰는 폰끼리 숙제·일정·스티커·한마디가 1~2초 안에 함께 바뀝니다.
- 인터넷이 없어도 이 폰에 먼저 저장되고(localStorage), 연결되면 가족 방과 다시 맞춰집니다. 공유 탭에서 백업·복원도 할 수 있어요.

## 규칙

- **칭찬 스티커**: 오늘 할 일을 **모두 완료**했을 때만 1개, **하루 1개**. 완료한 숙제를 다시 끄면 그날 받은 스티커(소원권까지 찼다면 소원권도)를 함께 회수합니다.
- **소원권**: 스티커 10개를 모으면 1장.
- **오늘의 한마디**: 오늘 탭에서 아이/엄마가 서로 한 줄 코멘트를 남길 수 있어요.

## 구성

- `index.html` — 앱 전체(단일 파일, 외부 의존성 없음)
- `apple-touch-icon.png` — 홈 화면 아이콘
